## 1. Ключевые обобщения и выводы

Decomposition Agent разбивает исходный запрос на 2–3 подзапроса, если он содержит несколько интентов. Это упрощает retrieval и позволяет решать multi-hop задачи через последовательную обработку более простых запросов.

Multi-source retrieval реализован через три независимых агента:
vector — поиск точных текстовых фактов (embeddings)
graph — поиск связей и multi-hop reasoning по knowledge graph
web — получение актуальной информации из интернета
Все три работают параллельно.
Эти агенты делают свой поиск и выдают ответ. Каждый retrieval-агент генерирует свой ответ (A_v, A_g, A_w).

В системе используется мультимодальная база знаний: изображения переводятся в текст (BLIP-2), объединяются с текстом и затем используются для построения графа знаний (entities + relations). Векторная база строится по этому же текстовому представлению.



Далее Decision Agent сравнивает ответы (BLEU/ROUGE), предварительно сумаризовав. Если они согласованы — выбирается результат, если нет — LLM делает финальный reasoning и объединяет ответы. Если нет вызывается ллм с исходным промтом и найденныим данными в каждом канале.
